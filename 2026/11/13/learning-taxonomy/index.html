学习智能体要会教，先得有一张能查询的先修图谱

资料核验：2026 年 11 月 13 日 18:05—18:10（新加坡时间），依据 withmarbleapp/os-taxonomy、luw2007/os-taxonomy-beijing、xiaoyang111222/cn-math-taxonomy 当时的 GitHub 元数据、README 与许可证文本，以及 Marble 官方站点。仓库仍在更新，主题数量、星标和课标对齐都会变化，细节请以各仓库最新页面为准。文中计数取自各项目当时公开的 README 摘要，作者没有下载数据包做独立清点，也没有安装、运行或测评这些工具，不构成选型或教学背书。

做一个“AI 老师”，最容易先做出对话框：学生提问，模型讲解，再出两道题。看起来已经在教了。真正先坏掉的，往往不是文采，而是顺序——它可能在分数除法还没站稳时，就开始讲应用题；也可能把“相关”当成“先修”，让学生在不该卡住的地方卡住。

课标和教材通常是给人读的文本，或锁在产品里的目录。智能体要用，得先能查询：这个概念之前必须掌握什么，掌握的证据是什么，这条依赖是硬门槛还是软帮助，它对齐的是哪一条课标。

最近在 GitHub 上更完整地公开出来的，正是这一层：把“学什么、先学什么”做成可查询的开放数据。它们不是又一个聊天产品，而是在补学习智能体最常缺的那张图。这和本博客前几天谈设计系统时的判断是同类问题：要让智能体用得上，接口得能被查询，而不能只靠一份容易过期的说明书。见《设计系统要让智能体用，先得能被查询，也能被测量》。

一、一张图，而不是一份目录

Marble Skill Taxonomy 由 Marble 发布，定位是小学阶段的开放学习图谱。2026 年 11 月 13 日读取的仓库 README 摘要是：版本 v1，1,861 个微主题，4,003 条先修边，覆盖 9 个学科。当时 GitHub 显示 7,688 星，许可证为 ODbL-1.0，当天仍有推送。

它把学习拆成可教的“微主题”。每个节点有通俗名称和描述、掌握证据、类型（概念、程序、表征、语言、元认知等）、学科与领域，以及大致年龄段。边是有向无环图：学 X 之前要先掌握 Y，并标出 hard 或 soft，附一句理由。微主题再链回被蒸馏出来的课标，README 点名的来源包括 NGSS、Common Core 和英国国家课程等。官方还提供交互式浏览页 withmarble.com/curriculum，可以点开一个概念，沿先修边往回看。

数据本身是 UTF-8 JSON，放在 data/ 里：topics.json 是节点，dependencies.json 是边，另有课标、领域摘要、教研记录和带 SHA-256 的 manifest.json。仓库强调这是纯数据，没有运行时依赖。用起来很直接：给定一个主题 ID，过滤先修边，就能取出一条路径；按学科和年龄段筛选，就能圈定范围。

这也是它和“再往提示词里贴一份课标”的差别。提示词会过期，模型会记错名称、编造依赖。图谱把关系写成可校验的结构，缺什么也可以被写明。例如教研记录是附加层，不是完整教学法：README 写明当时有 1,049 条记录，覆盖不完整，并且这些记录由智能体撰写，活动是有研究参考的提案，不是经过实证的干预；英文等学科在该层仍可能完全空白。仓库还明确排除了语义向量和任何儿童个人数据。

许可同样写得很清楚。数据库（集合、结构、ID 和关系）是 ODbL 1.0：可用于研究和商业，须署名，衍生数据库需保持开放。Marble 自己撰写的文本另用 CC BY-SA 4.0。课标摘录仍归各上游许可，见仓库的 PROVENANCE.md。按 README 的解释，ODbL 区分“衍生数据库”和“基于数据做出的产品”：改进图谱本身需要回馈开放，用它做产品不必开源整个产品。具体条款请以许可证原文为准，本文只转述项目自己的说明。

二、搬到另一种课标上，翻译只是第一步

英美课标对中国学生不能直接用。派生项目 os-taxonomy-beijing 试图把这张图译成中文，并对齐中国教育部《义务教育课程方案和课程标准（2022 年版）》，优先覆盖北京小学阶段。它把这件事拆成三步：翻译名称、描述、掌握证据和评估话术；把课标对齐从英美标准换成教育部 2022 版课标；同时尽量保留上游的 mt_ ID 和拓扑，以便继续同步。

更值得看的，是它把风险写在了仓库门口。2026 年 11 月 13 日读取的 README 仍标明状态为 v1.2.0-zh.0，成熟度是 alpha，数据集尚未经教师审核。当时已翻译微主题 1,590 / 1,590，其中 1,586 条标记为机器翻译，人工校对只有 4 条；另有 2,008 个中国特有微主题，2,619 条中国特有依赖。内部边的审核记录是 reviewed 1,326、machine 873、rejected 420，覆盖率 50.6%。仓库写明：未审核的 AI 推测边不进入儿童路径；reviewProvenance: ai-consensus 的 AI 复审，不等同于教师人工审核。cnStandards 里的编号是项目自建的映射标识符，不是教育部官方代码。它也不发布课标原文或教材 PDF。

同步策略本身很克制：中文文件只保存翻译字段，结构字段留在上游，通过相同 ID 合并。可是 11 月 13 日看到的上游摘要已经是 1,861 个微主题，派生仓库仍停在初始公开时的 1,590 个，最近一次推送停留在 2026 年 8 月 17 日。保留可同步的结构，和真的跟上上游，不是一回事。许可证上，数据库同样是 ODbL 1.0，文本为 CC BY-SA 4.0，代码为 MIT，使用时须保留对 Marble 的署名。

这条路线把一个容易被忽略的事实摊开了：本地化的难点通常不在“能不能机翻完”，而在课标映射是否站得住、未审核的边会不会混进学习路径，以及翻译能否持续跟上正在扩张的上游。

三、另一条路：按中国教材生长，并带上诊断

cn-math-taxonomy 走的是另一条路。它参考了 Marble 的节点与先修边格式，但从中国课标和人教版教材目录往上长，还附带自适应前置诊断和题库。在线演示在 math.pansgo.com。仓库名仍叫 cn-math-taxonomy，README 标题已扩大到语文、英语、物理、历史、地理、生物、化学等；11 月 13 日 GitHub 显示 7,932 星，当天亦有推送。

就数学而言，当时 README 顶部的分学段表写的是：小学到高中选择性必修合计 870 个知识点、1,459 条学段内部先修边，另有跨学段和跨模块的边；课标条目 314 条，题库 3,627 道。英语、物理、语文也各有分表。高中数学按人教 A 版（2019）的必修和选择性必修建点，英语从三年级到高中，语文目前到初中、没有高中语文。数学、英语、物理是分开的图，物理用到的数学写在 mathLinks 里，不算先修边。数学答错时，诊断可以沿先修边从高中、初中一直回溯到具体的小学知识点。

这些数字不宜直接加总，也不宜当成已经完工的“全学科官方图谱”。同一份 README 里，小学语文在总表和分节之间就有 493 与 494 的出入；GitHub 仓库简介仍写着较早的“1,644 个知识点、2,403 条先修边、6,723 道题”，已经落后于正文。更关键的是作者自己写在前面的限定：知识点拆分、掌握标准、诊断题答案，尤其是先修关系——哪些是 hard、哪些是 soft，甚至某条边该不该存在——都需要一线教师审核后，才能用于教学、诊断或学习路径推荐。高中题和英语题没有做盲解；部分册次目录标了“非官方、待核”；不少课标条文是公开转述，而不是逐字原文。题库由 AI 生成，规模不大，也没有用学生数据校准难度。

许可与 Marble 也不一样。该项目采用 CC BY-NC 4.0：个人学习、教学、研究可以免费使用并署名；README 写明不得用于付费课程、付费应用或机构收费服务等商业用途，商用需另行授权。条款以 LICENSE 和仓库说明为准。

四、图谱能做什么，不能代替什么

把这三份材料放在一起，对做学习智能体的人更有用的，不是选哪一个仓库当“标准答案”，而是看清这张图到底承担什么。

它能做的，是把教学顺序变成可查询、可校验的结构。学生在一个知识点上摔倒，系统可以沿先修边往回走，而不是只换一种讲法再讲同一点。按学科、学段或年龄圈定范围，也比把整本教材塞进提示词更可控。不同产品如果愿意共用或公开对齐同一层图谱，就不必每做一个辅导应用就重新发明一棵技能树。“教什么、先教什么”可以成为数据，“产品怎么说话、怎么动画”可以留在应用里。

它代替不了的，同样清楚。未审核的边不是学习路径；智能体写的教研记录，不等于课堂上验证过的教法；课标编号或转述，也不等于获得了原文或教材的使用权。题库更不是完整测评。北京派生项目把未审核的边挡在儿童路径之外，中国知识图谱项目把“先送教师审核”写进README，都是在提醒同一件事：开放数据降低了起步成本，并不自动等于可以上教学现场。

许可证也是查询接口的一部分。ODbL 和 CC BY-NC 都允许认真使用，但约束不同。把图谱接进要收费的产品之前，先读许可，比先调模型更要紧。

如果要做学习智能体，不必先追一个更会聊天的模型。更值得先问三个问题：这张图能不能被查询，“必须先会什么”有没有经过人的审核，以及你的用法是否落在许可范围内。对话框只是一层界面；先修图谱，才是它能不能教的那一层。
